# VSS Maps Studio

A 100% self-owned, API-key-free web mapping platform built with React, TypeScript, Leaflet, Tailwind CSS, and Turf.js.

## 🌟 Key Features

- **100% Owned & Free**: Powered entirely by OpenStreetMap, OSRM, Nominatim, and Open-Meteo. Zero paid API keys, subscriptions, or telemetry.
- **⏱️ Travel-Time Isochrones**: Calculate and plot 5m, 10m, 15m, and 30m reachability contours (driving, cycling, walking).
- **🏡 Overlap & Spot Finder**: Compute spatial buffer intersections to find ideal living or meeting spots relative to multiple locations.
- **☀️ Solar & Daylight Tracker**: Live real-time solar elevation, azimuth, daylight duration, sunrise, and sunset calculator.
- **🛰️ Multi-Layer Basemaps**: Standard OSM, Esri Satellite, CartoDB Dark, OpenTopoMap, CyclOSM, ÖPNVKarte Transit, OpenRailwayMap, and OpenSeaMap.
- **🔍 Global Geocoding & Routing**: Instant location search with Nominatim and multi-stop route planning with turn-by-turn directions via OSRM.
- **📍 Saved Places & Custom Pins**: Save custom markers with category colors, emoji tags, notes, and local storage persistence.
- **📏 Measurement & GeoJSON**: Distance and area spatial measuring tools with GeoJSON import/export capabilities.
- **360° Street View & Weather**: Mapillary community 360° panorama integration and live weather overlay.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/siddharth-1118/vss-maps.git
cd vss-maps

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
